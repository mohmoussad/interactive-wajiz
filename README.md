# Interactive Wajiz

An interactive educational project that transforms historical content into visual and explorable experiences.

The project is based primarily on the book **"التاريخ الإسلامي الوجيز"** by **محمد سهيل طقوش** and aims to make historical relationships, timelines, geography, dynasties, and key figures easier to understand through interactive web-based visualizations.

Rather than replacing the original text, this project serves as a companion resource that helps readers explore historical information in a more intuitive and engaging way.

## Vision

History is often presented as long blocks of text, static maps, and complex genealogies that can be difficult to visualize.

This project attempts to convert those elements into interactive experiences such as:

* Historical timelines
* Interactive maps
* Genealogy trees
* Historical relationship networks
* Character exploration pages
* Event and dynasty visualizations

The long-term goal is to build a visual knowledge base that allows users to navigate Islamic history through time, geography, and relationships.

## Current Features

### Historical Timeline

Explore Islamic dynasties, caliphates, and major historical entities through a visual timeline.

Features include:

* Zoom controls
* Historical period visualization
* Dynasty duration comparison
* Interactive entity exploration

## Design Principles

The user interface is inspired by:

* Historical atlases
* Classical manuscripts
* Museum exhibitions
* Library archives

The design aims to remain:

* Educational
* Elegant
* Minimal
* Accessible
* Historically themed without excessive decoration

## Technology Stack
